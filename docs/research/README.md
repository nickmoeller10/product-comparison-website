# Research appendices (2026-09-29)

Four research passes were run to verify facts used in the software proposal. The sandbox proxy blocked
direct fetches of many official domains, so several figures come from official-page search snippets or
third-party roundups. Every figure marked "verify" or "unverified" must be confirmed on the official page
before the business relies on it. None of this is legal advice.

- `google-seo-policy.md` — scaled content abuse, site reputation abuse, reviews guidance, AI content guidance, 2025-2026 update patterns, structured data eligibility, practitioner rules.
- `legal-data-sources.md` — Reddit, YouTube, Amazon, retailer APIs, search APIs, scraping case law, public spec datasets, professional reviews, other sentiment sources, and the recommended legal source stack.
- `affiliate-and-pricing.md` — affiliate program terms and rates, sub-affiliate networks, FTC rules, comparable subscription pricing, second-category recommendation.
- `stack-pricing.md` — free tiers and fees for Supabase, Vercel, n8n, AI providers and gateways, web data providers, email, payments, auth, monitoring, search, Keepa.
