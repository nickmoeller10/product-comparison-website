Batch notes:
1. Retailer floor: Best Buy 0-0.5% (new customers only, 1-day cookie); Newegg 1-2% (7d); B&H 2% base with a 60-hour cookie; Adorama 2%; Micro Center no formal program. Manufacturer-direct programs (Lenovo 5-7%, LG 6%, Dell Outlet/SMB 5-8%, TP-Link to 10%, UGREEN 8%+, Eufy 7-13%, Logitech 4-10%, Razer to 15%) are where the margin is.
2. Amazon 2026: electronics at the bottom (TVs and consoles 2%, PC/components 2.5%, headphones 3%, game software 1%); halo commissions cut to 1-2%; several lifestyle categories cut up to 50%.
3. RTINGS paywalled full test results March 2 2026; a free certification-backed spec database has an opening but cannot replicate measurements.
4. Best structured data: monitors, laptops, networking, peripherals (ENERGY STAR SODA API plus VESA, Wi-Fi Alliance, USB-IF, Thunderbolt, Bluetooth SIG, FCC ID, EPEAT, Matter/CSA). Audio, cameras, projectors rely on self-declared specs.
5. Highest value per effort: laptops/desktops, smart-home security, projectors, 3D printers. Highest demand but weakest economics: TVs, gaming hardware, smartphones.
